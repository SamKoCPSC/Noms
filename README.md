# Noms village — denser meadow (revision 10)

Download `noms-village-mobile.zip`, extract it and open `OPEN-VILLAGE-MOBILE.html` in Chrome. All twelve locations, the world, viewer code and font are embedded, so the preview does not fetch neighboring files.

The meadow now has 28,080 tufts and 84,240 blades: over twice as many tufts and 60% more blades. Daisy/buttercup/lavender patches, subtle ground color variation and ridged tree and shrub foliage are preserved. Planting leaves stone paths and entrances clear. Shared outdoor daylight is rebaked. The room models and approved camera route are preserved.

Use Walk tour, previous/next, the location menu or Overview. This is a review prototype, not the deployed About page.

Textures use WebP quality 76 at their original dimensions; repository GLBs retain lossless PNG textures. Geometry buffers are unchanged by preview packaging. The archive uses optimized standard ZIP Deflate compression; ordinary ZIP readers can extract it.

Verified in desktop Chromium at desktop and portrait sizes, including blocked external requests. Direct Android file launching and phone performance are not measured.
