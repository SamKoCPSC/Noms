# Shared navigation explorations v1

Ten exploratory desktop concepts generated with the built-in image generation tool. N1 + N4 is the selected navigation-bar direction; no app code is changed. Warm cream/sage/coral, rounded Fredoka-style headings and Nunito-style labels, gentle neumorphism and the approved book-logo direction inform all concepts. Exact fonts and A3 logo must be applied in implementation.

## Selection — 2026-09-12

Combine **N1 Cozy Counter's familiar horizontal layout** with **N4 Floating Pantry's floating rounded shape**. Retain the slightly inset cream bar, A3 book logo, coral Noms wordmark, compact labelled links, sage active state, inset search and softly raised coral New recipe action where appropriate. Keep neumorphic depth gentle and omit N4's surrounding decorative props and heavy framing.

The other eight concepts remain exploration history, not selected requirements. Next refine desktop, portrait tablet and phone, signed-out/signed-in variants, dark mode, overflow, account access and accessible interaction states. Exact destinations remain subject to existing product behavior, not generated labels.

Canonical decision: [NOMS-020 implementation plan](../../implementation-plans/NOMS-020-visual-design-refinement.md#selected-shared-navigation-direction--n1--n4).

## Review boundaries

Compare navigation architecture and character, not exact generated body layouts or copy. Body content varies despite the shared prompt. Generated meal planning, favourites/hearts, slogans, counts, profile identities, or other unrequested features are not requirements. Recipes and Drafts labels are proposed information architecture, not promises of separate existing routes. Public/signed-in variants, dark mode, responsive layouts, keyboard focus, contrast, overflow and touch targets need refinement after selection. Navigation must not depend on shadows or icons alone.
