Generated fonts, logo, state, copy and quantities are illustrative. E3A/B/C omit their requested on-image titles: identify by filename and this index. E3A/B select Private while E3C selects Public; this is illustrative, not a change to application defaults. E3C's bottom tray needs tested scroll padding so it cannot obscure fields. E3D illustrates the same document scrolled to Method, not a separate method page. Reorder boundaries are sometimes incorrect in generated controls; disable first-up and last-down within the appropriate group. Add substep must identify its parent. Method textareas must grow for long content. Keep all visibility options and private draft status separate, preserve existing publication and discard safeguards, and validate accessibility and dark mode before implementation.
