# Recipe editor directions v1

Ten desktop-only concepts generated with the built-in image generation tool, 2026-09-13. Uses preferred R3A Soft Album styling and selected N1/N4 navigation. No editor direction selected; no application code changed. Phone/tablet remain deferred.

## Boundaries and review

Visual QA: all ten concepts generated. E1/E2 converge on similar two-column compositions. E3/E4/E8 omit Unlisted; restore that option. E5's Method inset is a comparison example, not simultaneous tab behavior. E7 misplaces the shared navigation above only part of the screen; retain full-width N1/N4 navigation and ensure preview reflects R3A exactly. E6 duplicates Add group controls and groups pasta cooking under Sauce; refine grouping. E10 duplicates Upload on individual photos; distinguish collection-level add from per-image edit/remove and preserve image reordering. Several method fields are too shallow for long instructions. Avatar/photo and unit/equipment representations are illustrative, not new data-model decisions. Maintain soft depth and the actual fonts/logo rather than generated approximations.

Compare layout and hierarchy, not exact generated fonts, A3 logos, field schemas, copy or data. Inset inputs and gently raised panels must retain clear boundaries and contrast. Private autosaved drafts and visibility when published are separate concepts. Status must reflect actual server save state; publishing remains explicit. Existing editor data model, validation, upload/edit/reorder, nested steps, discard safeguards and publication/version behavior remain authoritative. Preview, local tabs/index, group controls and alternate layouts are exploratory interaction proposals, not authorized new features. Reordering needs keyboard-accessible actions, not drag only. Preserve Public/Unlisted/Private options even if a generated board omits one. Do not infer a fixed unit vocabulary, automatic total-time calculation or changed draft lifecycle from the images.

Remaining: errors/pending/offline save feedback, validation and focus, avatar-free image upload/edit/remove/reorder states, long ingredients/nested methods, equipment, missing photos, discard confirmation, publishing/visibility confirmation, preview accuracy, dark mode and accessibility. Exact labels and action hierarchy need reconciliation with current code before implementation.
