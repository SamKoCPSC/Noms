# Introduction painted icon

Generated 2026-10-30 with the image-generation tool. A coral open door with an
olive leaf, cream interior, and olive frame represents the public welcome page.
The painted finish and palette match the existing Noms navigation icons.

`introduction-v1.png` preserves the generated square canvas and transparent alpha
channel. `PageIconKind::Introduction` produces the same 192px WebP derivative as
the other page icons. The navigation drawer and mobile account hub use this
icon beside the Introduction link.
