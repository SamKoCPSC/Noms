# Kitchen painted icon

Generated 2026-10-30 with the image-generation tool from the selected grocery
basket concept. The olive basket, cream handle, coral tomato, green leaves, and
attached checklist match the existing Noms painted navigation icons.

`kitchen-v1.png` preserves the generated transparent alpha channel and square
canvas. The shared `PageIconKind::Kitchen` asset uses the same 192px WebP
derivative and navigation sizing as the other page identities.

The icon appears beside the shared Kitchen workspace heading, in the navigation
drawer, and in the mobile creation menu's pantry and grocery list entries. The
compact bottom navigation retains its shared line icon style.
