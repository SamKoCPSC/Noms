# Sign-in provider marks

Official provider artwork retrieved 2026-09-24. Used to identify the existing OAuth providers; marks are decorative beside the full accessible labels.

- `google-g.png`: https://developers.google.com/static/identity/images/g-logo.png, linked by https://developers.google.com/identity/branding-guidelines. Original multicolor mark on a white icon backing.
- `GitHub_Invertocat_Black.svg`: original SVG from https://brand.github.com/GitHub_Logos.zip, linked by https://brand.github.com/foundations/logo.

The surrounding controls use NOMS' selected shared outlined-button style and Nunito. These trademarks belong to their respective owners.
