# Riverside Cabin Campsite

Intended About-tour section: **Respecting your privacy.**

## Reconstruction status

This is a new reconstruction from the approved design discussion. The earlier uncommitted workspace artifacts were lost; this is not a recovered byte-identical copy.

Corner composition with a two-storey cabin, river, no fence or tent, a wooden slatted porch chair, simple tiered evergreen trees with shallow folds, and camping food around an outdoor picnic and fire area.

The draft PR is opened before regeneration so source, native Blender masters, GLB exports, previews, and validation reports can be saved incrementally in GitHub. Generated artifacts will be added as they pass review. App integration is a separate step.
