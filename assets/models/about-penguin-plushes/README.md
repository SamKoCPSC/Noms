# About-tour penguin plush companions

Fifteen small penguin plushes added to the twelve active About scenes. Indoor
scenes receive one each; the farmers’ market, riverside campsite and garden
receive two each. Existing bedroom penguins remain in place.

Four scarf colors (blue, sage, berry and honey) share soft felt shapes, stitched
scarves, cream faces, orange feet and drooping flippers. Each plush adds 2,656
triangles and one draw call, with no new image textures. They use the tour’s
shared matte lighting, dynamic shadows and three-second entrance choreography.

## Editable source and production integration

`placements.json` records each variant, size, orientation, furniture support and
base-file hash. Positions are glTF Y-up; the native-master helper converts them
to Blender Z-up. The four editable variants are generated by:

```sh
blender -b --python assets/models/about-penguin-plushes/source/build_plush_library.py
```

The original scene masters remain unchanged. To make a separate editable native
scene with its plushes, run (example):

```sh
blender -b assets/models/monochrome-social-kitchen/models/monochrome-social-kitchen.blend \
  --python assets/models/about-penguin-plushes/source/apply_to_master.py -- \
  social-kitchen /tmp/social-kitchen-with-plush.blend
```

The production pass appends accessories to the existing optimized GLBs. It
preserves the complete original binary buffer, materials, transforms, UVs,
accessors and primitives, including the older rooms’ surface atlases. It does
not re-export or simplify their existing furniture. For a reproducible rebuild,
first extract the recorded clean baseline:

```sh
mkdir -p /tmp/about-plush-base
git archive da47d8b908ab566ddf96cd2b66c8213621a6ef95 assets/about | tar -x -C /tmp/about-plush-base
python tools/about/add_penguin_plushes.py --base-dir /tmp/about-plush-base/assets/about
python tools/about/verify_penguin_plushes.py --base-dir /tmp/about-plush-base/assets/about
```

Use those clean inputs, not the already decorated GLBs. The tool rejects a
changed baseline so that placements must be reviewed when furniture changes.
`integration-audit.json` records each addition and the preserved buffer hash.
The verification script checks byte preservation, renderer budgets, and actual
furniture triangles beneath both feet. Rust loader tests check all twelve
composed models and their entrance bounds; browser checks verify every plush
assembly loads through the actual tour renderer.

## Review images and reading-mode posters

The checked-in previews render the composed production GLBs, with the older
rooms’ external color maps restored. They are Blender renders, not browser
screenshots. The shared runtime shader applies its own lighting in the app.

```sh
blender -b --threads 2 --python assets/models/about-penguin-plushes/source/render_review.py -- kitchen /tmp/plush-review
```

Repeat for each `model` key in `placements.json`; `library-gallery` renders the
four plush variants. Full scenes are 1080 × 945, close-ups 480 × 480. The matching
`assets/about/sams-*.webp` files show the plushes in reading and fallback modes.
After rendering every scene, publish them with:

```sh
python assets/models/about-penguin-plushes/source/publish_previews.py /tmp/plush-review
```
